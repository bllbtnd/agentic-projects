# Crisis Map

Public, non-commercial map. This folder is the product. Apps:

- `pipeline/` ingest and static files
- `web/` the map
- `shared/` contracts
- `ops/` budgets and later SRE checks (`@crisis-map/ops`)
- `data/reference/` Data Analyst lists
- `docs/` product docs

Nothing here is wired to a database or a long-running server.
